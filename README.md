# dsh-unlag（解除卡顿）

**改完插件点一下就生效。界面卡了点一下就顺。正在跑的任务不受影响。**

窗口右上角一个按钮，不重启进程、不刷新掉会话：插件代码原地换掉，老旧卡顿的界面重建一次。

## 两个日常场景

| 情况 | 按一下 |
| --- | --- |
| 改了插件，手里还有任务在跑 | 大部分插件当场更新，任务继续跑完 |
| 界面越用越卡 | 直接恢复流畅，会话、队列、草稿都还在 |

以前两种都得重启 App。现在不用，也不用挑空闲时间——马上换，不等。

## 装

```sh
dsh plugin install dsh-unlag
```

重载一次 App 让它进来，之后所有更新都走按钮。

## 用

点右上角那个按钮。设置两行决定它做什么：

- **按下刷新时换掉插件代码**（默认开）
- **按下刷新时重建界面**（默认开）

都开＝先换代码再重建；只开一个＝另一项完全不动；都不开＝点击无反应。

## 不会丢什么

- 轮次、子代理、终端进程：在宿主侧，一路继续。
- 排队消息、输入草稿、附件：重建前先提交焦点里的内容。
- 有未保存改动或开着弹窗：重建被拦下并提示，不硬刷。
- 从不自己重启或退出 App；启动模块缺失时宁可放弃重建并提示，也不冒把 App 带下去的风险。

管不到：独立进程和进程级的东西（宠物窗口自己的配置、DSH 自身升级、原生依赖变化）。

## 排错

- 日志：`~/.dsh/unlag-reload.log`，换代码／跳过／被拦各一行含原因。
- 状态：`GET /dsh-unlag/state` → `{"plugins":true,"page":true}`。
